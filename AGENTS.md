# Agents working in this repository (Codex, Claude Code, any other tool)

Read `CLAUDE.md` in full before doing anything. It is the project manual and
the memory of every decision; a change made without it has been wrong often
enough that this file exists to say so.

## Before material Arrington work: Google Drive first, every time

The repository governs the code. It does not govern brand, positioning,
pricing, worker authority or what the website or the advertising may say.
Those live in the controlled Google Drive folder ARRINGTON CONSULTANCY BRAIN.
Read, in this order, before any change that touches copy, offers, prices,
advertising or worker scope:

1. START HERE. ARRINGTON CONSULTANCY BRAIN INDEX
2. 00 ARRINGTON BRAND OPERATING SYSTEM
3. 01 ARRINGTON CURRENT OPERATING POSITION
4. The worker's own START HERE, operating manual and Worker Handoff Log
   (Website & Hosting for this repository; Google Ads for the Ads account).

Your first reply to Tom quotes the title and last-updated date of each
document you read, the heading and date of the last entry in the Handoff
Log, and the next controlled action it names. Make no live change until he
has replied. The full block is "WORKER START BLOCK" in Drive.

## Which worker you are

- Code, deploys, landing pages, conversion tag code: the Website & Hosting
  worker. Write back to its Handoff Log.
- Changes in the Google Ads account itself (keywords, negatives, bids,
  budgets, ads): the Google Ads worker, whichever tool is running. Read and
  write back to the Google Ads Handoff Log, not the website one. One session
  at a time on that account.

## Standing rules that do not change by tool

- Never put a secret in code, git, Drive or chat.
- Never claim to have checked, tested, deployed or verified anything unless
  the action actually happened, and say which of these it was.
- Spend, bidding, ad copy, prices and public copy are proposals to Tom.
- UK English, "we" on the website outside Useful Thinking, no em dashes, no
  fire metaphors, and the Brand Operating System's banned word list.
